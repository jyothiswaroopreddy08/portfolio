About

Reliability isn't luck — it's engineered.

I started at Infosys in 2021 building a Python-based monitoring engine for Jenkins — not because anyone asked me to, but because I hated watching engineers lose hours to opaque pipeline failures. That instinct — fix the friction before it compounds — has defined how I work ever since.

Over the past 4 years I've led a full-scale migration of CI/CD infrastructure from Jenkins to GitHub Actions, standardized multi-cloud provisioning across AWS, Azure, and GCP using Terraform, and embedded security scanning directly into delivery pipelines. I mentor junior engineers, conduct code reviews, and believe the best DevOps work is invisible to the teams it enables.

I'm based in Nellore, Andhra Pradesh, currently at Infosys as a Technology Analyst — and I'm always interested in hard infrastructure problems worth solving.

04

codeql-secops

PR-scoped CodeQL alert filter to eliminate security noise
DevSecOps · Zero alert fatigue
Challenge

Static analysis produces too much noise. Teams were ignoring alerts because they couldn't distinguish issues introduced in the current PR from pre-existing ones in the codebase.

Approach

Built a GitHub Actions post-processing step that filters CodeQL SARIF output to surface only alerts introduced by the current pull request. Teams now see signal, not noise — merges can be gated on real risk, not alert count.
